# AWS 네트워크 설정 단계

1. **리전 선택**
   - 리소스를 배포할 AWS 리전을 선택합니다.

2. **VPC 생성**
   - 가상 사설 클라우드(Virtual Private Cloud)를 생성합니다.
   - CIDR 블록을 설정합니다.

3. **서브넷 생성 (라우팅 테이블)**
   - VPC 안에 서브넷을 생성합니다.
   - 라우팅 테이블을 연결하여 트래픽 흐름을 설정합니다.

4. **보안 그룹 설정**
   - 인스턴스 접근을 제어하는 보안 그룹을 생성하고 규칙을 설정합니다.

5. **연결**
   - 생성된 VPC, 서브넷, 보안 그룹을 필요한 리소스(예: EC2)와 연결합니다.
